### Added

- Initial public release of the PrimeUnits marketplace codebase (Laravel 13 + React/Inertia).
- Redesigned "Find a Unit" homepage search experience with a category → classification → contextual filters flow.
- Category/classification taxonomy covering cars, motorcycles, commercial vehicles, agricultural equipment, heavy equipment, electric vehicles, and other units.
- Shared listing search scope used by both the homepage search and the full listings catalog.
- `README.md` with setup instructions and demo seed accounts.
- `LICENSE` (MIT).
- `CONTRIBUTING.md` with code style, test, and pre-PR checklist guidance.
- `CODE_OF_CONDUCT.md` (Contributor Covenant v2.1).
